# Public Scope

This repository publishes only reviewed, redistribution-safe project material:
handwritten RTL, ASIC-portable and optimized RTL, testbenches, checkers, public
vectors and constraints, deterministic documentation scripts, and sanitized
evidence summaries.

The repository intentionally excludes PDK and standard-cell or SRAM libraries,
license files and servers, credentials, commercial tool payloads, generated
Xilinx IP, third-party proprietary source, EDA work databases, wave databases,
large raw logs, checkpoints, and bitstreams. Machine-specific paths, user names,
host names, and network addresses are removed from public evidence.

The uncommitted Vivado comparison in the protected source workspace is excluded
from the first public release. Only the previously accepted FPGA baseline may be
reported until that comparison is independently completed and reviewed.
