# Vivado boundary

The accepted historical FPGA baseline used generated Xilinx IP that is not
redistributed here. Therefore this directory does not claim to reproduce that
baseline.

`Invoke-PortableExperiment.ps1` is an explicitly experimental, XCI-free synthesis
entry for the portable/divopt top. Its results must be reported separately from
the accepted baseline and cannot be used until reviewed. The protected source
workspace's uncommitted original/divopt comparison remains `IN PROGRESS / EXCLUDED`.
